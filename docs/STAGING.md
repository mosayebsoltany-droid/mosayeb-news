# آزمون پذیرش و محیط Staging — نسخه ۰٫۴٫۰

این محیط برای ارزیابی نسخهٔ شبیه‌سازی است. اتصال رسمی به ثبت اسناد به قرارداد API، احراز هویت سازمانی، دسترسی محیط آزمون و تأیید فرایند نیاز دارد.

## اجرای مجزا

روی میزبان دارای Docker، کلید تصادفی را در محیط نگه دارید. مقدار آن را برای استفاده مجدد در Secret Manager حفظ کنید.

```bash
export BROKER_JWT_SECRET="$(python -c 'import secrets; print(secrets.token_urlsafe(48))')"
docker compose -f compose.staging.yaml up --build --detach --wait --wait-timeout 120
curl -fsS http://127.0.0.1:8001/health
docker compose -f compose.staging.yaml exec broker python -m app.create_user uat_broker
```

دیتابیس این محیط در ولوم `broker-staging_staging-data` و پورت میزبان ۸۰۰۱ است. سرویس‌های بدون ورود `/api/demo/requests` در این محیط غیرفعال‌اند. حساب با CLI ایجاد می‌شود و رمز به‌صورت تعاملی دریافت می‌شود.

برای دسترسی از دامنهٔ مشخص، پیش از اجرا `BROKER_ALLOWED_HOSTS` را با فهرست دامنه‌ها، بدون پروتکل یا مسیر تنظیم کنید. `localhost,127.0.0.1` را برای آزمون سلامت حفظ کنید. محیط پشت پراکسی HTTPS قرار می‌گیرد. دمو Codespaces به دامنهٔ دقیق پورت خودش در این متغیر نیاز دارد.

`BROKER_CORS_ORIGINS` به‌طور پیش‌فرض خالی است. برای فرانت‌اند در دامنهٔ جدا، مبدأ کامل مانند `https://portal.example.test` را مشخص کنید. مبدأ ستاره‌ای و ارسال خودکار کوکی فعال نیست. توکن Bearer در هدر ارسال می‌شود.

## اجرا و شواهد آزمون

```bash
python -m pip install -r requirements-dev.txt
python -m pytest test_main.py test_scenarios.py -v
```

تست‌ها پایگاه دادهٔ موقت و خطاهای کنترل‌شده دارند. نتیجهٔ قطعی و Circuit Breaker به تصادف وابسته نیست. لاگ‌های برنامه با نام `broker.errors`، نوع خطا و شناسهٔ قابل تطبیق با پاسخ ثبت می‌شوند. پیام کاربر ادعای ارسال اعلان به تیم پشتیبانی ندارد.

## محدودیت‌های تحویل

Circuit Breaker در حافظهٔ هر پردازش است. وضعیت مشترک چند پردازش، آزمون بار، تست نفوذ مستقل، محدودسازی نرخ ورود و سامانهٔ پایش و اعلان هنوز نیاز به طراحی و اجرا دارند. فایل نقشه فعلاً فقط برای ثبت درخواست آزمایشی دریافت می‌شود. دادهٔ شناسایی واقعی وارد دمو عمومی نشود.

خطای ۴۰۴ روی گوشی کاربر همچنان باز است. پاسخ موفق از Codespaces یا شبکهٔ آزمون، تأیید دسترسی از گوشی کاربر محسوب نمی‌شود. راه‌اندازی staging محلی و نتیجه CI، شواهد فنی جدا از این مسئله‌اند.
