# پیکربندی و کلیدها

| نام | کاربرد | وضعیت و محل نگه‌داری |
| --- | --- | --- |
| `BROKER_DATABASE_URL` | مسیر SQLite | فعال. بدون Docker فایل `broker.db` در ریشه و در کانتینر `sqlite:////data/broker.db` است. |
| `GITHUB_TOKEN` | انتشار ایمیج در GHCR | GitHub Actions در هر اجرا ایجاد می‌کند. مجوز `packages: write` فقط برای job انتشار تنظیم شده است. |
| توکن GHCR با `read:packages` | دریافت بسته خصوصی روی ماشین مقصد | در صورت نیاز، توکن و دسترسی بسته را در حساب GitHub تنظیم کنید. رمز ورود را با `--password-stdin` وارد کنید. |
| `BROKER_JWT_SECRET` | امضای JWT | نام پیشنهادی برای مرحله احراز هویت. در نسخه فعلی مصرف نمی‌شود. مقدار در محیط اجرای برنامه نگه‌داری شود. |
| `DEEPSEEK_API_KEY` | اتصال اختیاری به DeepSeek | فقط در صورت پیاده‌سازی و فعال‌سازی اتصال در آینده. مقدار در محیط اجرای برنامه نگه‌داری شود. |

برای اجرای دموی فعلی هیچ API Key لازم نیست. مقادیر واقعی کلیدها در کد، CHANGELOG، تیکت، فایل Docker و لاگ ثبت نشوند. برای اجرای محلی از محیط پردازش و برای گردش‌کار یا Codespaces از بخش Secrets مربوط به همان محیط استفاده کنید.

| مسیر فعال | کاربرد |
| --- | --- |
| `GET /` | وضعیت دموی پایه |
| `GET /health` | بررسی دسترسی به دیتابیس |
| `GET /docs` | Swagger UI |
| `GET /openapi.json` | قرارداد ماشین‌خوان API |

مسیرهای ورود، سرویس‌های ثبتی و گواهی PDF در فهرست کارهای بعدی هستند. مشخصات سامانه رسمی و کلید آن هنوز تعیین نشده است.
