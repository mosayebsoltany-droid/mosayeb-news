# پیکربندی و کلیدها

| نام | کاربرد | وضعیت و محل نگه‌داری |
| --- | --- | --- |
| `BROKER_DATABASE_URL` | مسیر SQLite | فعال. بدون Docker فایل `broker.db` در ریشه و در کانتینر `sqlite:////data/broker.db` است. |
| `GITHUB_TOKEN` | انتشار ایمیج در GHCR | GitHub Actions در هر اجرا ایجاد می‌کند. مجوز `packages: write` فقط برای job انتشار تنظیم شده است. |
| توکن GHCR با `read:packages` | دریافت بسته خصوصی روی ماشین مقصد | در صورت نیاز، توکن و دسترسی بسته را در حساب GitHub تنظیم کنید. رمز ورود را با `--password-stdin` وارد کنید. |
| `BROKER_JWT_SECRET` | امضای JWT | برای مسیرهای محافظت‌شده لازم است. دست‌کم ۳۲ بایت، در محیط اجرا یا Codespaces Secrets. |
| `DEEPSEEK_API_KEY` | اتصال اختیاری به DeepSeek | فقط در صورت پیاده‌سازی و فعال‌سازی اتصال در آینده. مقدار در محیط اجرای برنامه نگه‌داری شود. |

برای اجرای دموی فعلی هیچ API Key لازم نیست. مقادیر واقعی کلیدها در کد، CHANGELOG، تیکت، فایل Docker و لاگ ثبت نشوند. برای اجرای محلی از محیط پردازش و برای گردش‌کار یا Codespaces از بخش Secrets مربوط به همان محیط استفاده کنید.

| مسیر فعال | کاربرد |
| --- | --- |
| `GET /` | وضعیت دموی پایه |
| `GET /health` | بررسی دسترسی به دیتابیس |
| `GET /docs` | Swagger UI |
| `GET /openapi.json` | قرارداد ماشین‌خوان API |

| `POST /auth/token` | ورود با نام کاربری و رمز و دریافت JWT سی دقیقه‌ای |
| `POST /services/claims` | ثبت ادعا با داده ساختگی و حداکثر سه تلاش در خطاهای موقت |
| `POST /services/maps` | درخواست آزمایشی نقشه با فایل غیرخالی تا ۵ مگابایت |
| `GET /services/track/{tracking_code}` | مشاهده درخواست توسط مالک آن |
| `POST /mock-registry/submit` | شبیه‌ساز ثبت، با نرخ خطای قابل تنظیم |

برای نسخهٔ آزمایشی، `BROKER_MOCK_FAILURE_RATE` به‌طور پیش‌فرض `0.2` است. آن را بین صفر و یک تنظیم کنید. ادعای نامعتبر با ۴۲۲ و قطعی پس از سه تلاش با ۵۰۳ پاسخ داده می‌شود. در قطعی، پاسخ همچنان کد پیگیری دارد. کد ملی و فایل در پایگاه داده ذخیره نمی‌شوند. برای این محیط فقط از دادهٔ ساختگی استفاده کنید. خروجی PDF در فاز ۵ اضافه می‌شود.

برای آزمایش API پس از نصب وابستگی‌ها، این دستورها را در ترمینال اجرا کنید:

```bash
export BROKER_JWT_SECRET="$(python -c 'import secrets; print(secrets.token_urlsafe(48))')"
python -m app.create_user broker
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

در Swagger روی **Authorize** بزنید و با حساب ساخته‌شده وارد شوید. برای ادعا کد ساختگی `0123456789` و نوع `demo` را وارد کنید. برای اجرا با Compose، متغیر JWT را در محیط میزبان تنظیم و با `docker compose run --rm -e BROKER_JWT_SECRET broker python -m app.create_user broker` حساب را ایجاد کنید. سپس کانتینر را بالا بیاورید. رابط `/portal` مسیر آزمایشی مستقل خود را دارد.
